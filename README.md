# SNAP BOOK — Company Knowledge Base

**A single handbook explaining how SNAP's AI document review works, so underwriters know exactly why a document passed or failed and what to do next.**

[Live site](https://piperintech.github.io/KnowledgeBase/) · Built for SNAP Insurance Service LLC

---

## The problem

SNAP introduced an AI layer (built with the vendor Inaza) that automatically checks discount and ID documents in Modotech. Underwriters had no clear reference for what the system checked, which thresholds it used, or how to handle a FAIL. So the same questions came up every day and reviews were inconsistent.

## What's inside

- **How the system works:** Agent uploads → OCR → data extraction → rules → result written back → underwriter reviews only the exceptions
- **5 automated checks**, each with *What it validates*, *Requirements & thresholds*, and *Examples*:
  - Homeowners discount
  - Prior coverage
  - In-agency transfer
  - E-signature
  - IDs
- **PASS vs FAIL:** PASS clears the task automatically. FAIL keeps it open with a plain-English reason.
- Searchable, sectioned layout built for a quick lookup in the middle of a task

## Stack

Single-file HTML/CSS/JavaScript · CLADIS design system · GitHub Pages
